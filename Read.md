# QuizVerse 🚀

An interactive and modern quiz platform designed for students and tech enthusiasts.  
This project combines fun games, coding quizzes, aptitude challenges, and leaderboard features in a single web application.

---

## 🌟 Features

- 🎯 Coding Quizzes
- 🧠 Aptitude & Logical Questions
- 🎮 Fun Interactive Games
- ⏳ Quiz Timer System
- 📊 Live Score Tracking
- 🏆 Leaderboard
- 📱 Responsive Design
- 🌙 Attractive Modern UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages (for deployment)
